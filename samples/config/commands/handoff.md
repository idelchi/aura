description: Update the workspace handoff with verified progress and the next action.
---

Update the project's existing handoff file, or create HANDOFF.md in the current workspace if none exists. Respect any
project-specific format. Record the active objective, accepted decisions, current changes, completed checks with their
results, unresolved issues and the next action. Preserve unrelated work and useful existing context. Link substantial
evidence instead of copying logs. Include no secrets. Do not claim unrun tests passed, start another task, push or deploy.
Finish by stating the handoff path and the immediate next step.
